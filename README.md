# Сайт журнала «МНОГО»

Учебный проект для деплоя на VPS (виртуальный выделенный сервер).  
Реализован на Flask с статическими файлами (HTML, CSS, JS) и динамическими анонсами.

## Основные возможности
- Отображение статических страниц (главная, разделы журнала).
- Динамические анонсы статей (данные могут загружаться из JSON или базы данных).
- Готовность к запуску в контейнере Docker.

## Технологии
- **Python 3.11** (язык)
- **Flask 3.0.3** (веб-фреймворк)
- **Docker** (контейнеризация)
- **HTML / CSS / JavaScript** (фронтенд в папке `public/`)

## Локальный запуск (без Docker)

1. **Создать виртуальное окружение**  
   ```bash
   python -m venv venv
   
2. Активировать окружение

Windows: .\venv\Scripts\activate

Linux / Mac: source venv/bin/activate

3. Установить зависимости:

pip install -r requirements.txt

4. Запустить приложение

python app.py

5. Открыть в браузере: http://127.0.0.1:5000

## Запуск через Docker

1. Собрать образ:

docker build -t mnogo_a5 .

2. Запустить контейнер:

docker run -p 5000:5000 mnogo_a5

-d — запуск в фоновом режиме (detached).

-p 5000:5000 — проброс порта: порт 5000 контейнера доступен на порту 5000 хоста.

3. Проверить, что контейнер работает:

docker ps

4. Открыть в браузере: http://localhost:5000

5. Остановить контейнер:

Сначала узнай ID контейнера или имя (если не задано явно), например, из вывода docker ps.

Затем выполни: docker stop <ID_или_имя>
